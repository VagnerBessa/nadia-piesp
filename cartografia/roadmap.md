# Roadmap Mobile

## Prioridade Atual

Estabilizar a equivalencia funcional com o Nadia Mobile mais recente, trocando apenas o dominio analitico para empreendedorismo.

## Backlog

- Testar voz com perguntas de abertura, MEI, Inova Simples e ranking municipal.
- Refinar respostas para distinguir estoque de empresas ativas e aberturas por periodo.
- Criar testes automatizados pequenos para `empreendedorismoDataService`.
- Revisar o texto de onboarding mobile para deixar claro que o app responde sobre empresas em SP.
- Avaliar remocao de componentes desktop restantes que nao sao importados por `App.tsx`.

## Fora do Escopo Mobile

- Dashboard generativo completo.
- Data Lab.
- Perfil municipal com mapa 3D.
- Upload de bases.
- Consultas locais em CSV, Parquet ou banco WASM no browser.
